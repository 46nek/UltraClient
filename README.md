# Krunker Ultra Client

「Krunker.io」を極限まで軽く、かつ超低遅延でプレイするためにゼロから開発されたC++ / WebView2製の完全特化型クライアントです。

ブラウザ本来のオーバヘッドや不要な処理を極限まで削ぎ落とし、OSレベルからのチューニング（タイマー解像度、Raw Input、DXGIレイテンシ調整など）を施すことで、これまでの専用クライアントを凌駕するレスポンス速度とエイムの安定性を実現しています。

## 🚀 主要機能 (Features)

*   **完全な Win32 Raw Input (PointerRawUpdate)**
    ブラウザの標準的なマウスイベント処理をバイパスし、OSの最深部（WM_INPUT）からレンダラーへ直接生データを流し込みます。高ポーリングレートマウス（1000Hz〜4000Hz）でも処理落ちやPing跳ね上がりが発生せず、絶対的な「フリックエイム」と「追いエイム」の安定感を提供します。
*   **System Timer Resolution (0.5ms) 強制化**
    Windowsの内部時計を標準の15.6msから最高限界値の0.5msへ強制的に引き上げます。OSのタスク切り替えや入出力処理の待ち時間が実質ゼロになり、「クリックした瞬間に弾が出る」究極のダイレクト感を実現します。
*   **DXGI Hook / 強制VSync無効化**
    GPUのフレームバッファ（IDXGISwapChain）を直接フックし、`SyncInterval=0` を強制することで、WebView2特有のティアリング防止機構による遅延を完全に剥がし取ります。
*   **自動メモリパージ (Auto Memory Cleaner)**
    WebView2（V8エンジン）のガベージコレクション（GC）を定期的に自動実行。何時間プレイし続けてもメモリのゴミが溜まらず、起動直後の最高の軽さを維持し続けます。
*   **極限軽量化フラグ (Bloat Reduction)**
    WebRTC、Speech API、最適化ヒント、翻訳機能など、FPSゲームにおいて一切不要なブラウザ機能を起動引数から根こそぎ無効化しています。
*   **リソーススワッパー & ユーザースクリプト対応**
    テクスチャ、モデル、サウンドのローカル置換（swapper）と、CSS/JSの注入（scripts）に標準で対応。

## 📂 フォルダ構成と使い方

*   `swapper/`: この中にKrunkerのリソースファイル（テクスチャや音声）を配置すると、自動的にゲーム内のデータが差し替わります。
*   `scripts/`: この中に `.js` ファイルを配置すると、ゲームロード時に自動実行されます。初期状態で `auto_memory_cleaner.js` が導入されています。
*   `ui/`: クライアント専用のUIや設定画面のHTML/CSS/JSが含まれています。

## 📥 ダウンロードと使い方 (Installation)

1.  GitHubの **[Releases ページ](https://github.com/46nek/UltraClient/releases)** から、最新の `KrunkerUltraClient_vX.X.zip` をダウンロードします。
2.  ダウンロードしたZIPファイルを右クリックし、「すべて展開」で任意のフォルダ（デスクトップなど）に解凍します。
3.  解凍したフォルダ内にある `KrunkerUltraClient.exe` をダブルクリックして起動します。
    *   ※ TCPレジストリ最適化（通信遅延の極限化）を使用する場合は、exeファイルを右クリックして **「管理者として実行」** を選択してください。

## ⚙️ 開発者向け: ソースからのビルド (For Developers)

ご自身でソースコードを改変してビルドしたい方向けの手順です。
Windows環境と Visual Studio 2022 (C++ ワークロード) が必要です。

1.  このリポジトリをクローンします。
2.  プロジェクト直下にある `build.bat` をダブルクリック、またはコマンドプロンプトから実行します。
3.  自動的にCMakeの構成とMSBuildによるコンパイルが行われます。
4.  ビルドが成功すると `build/Release/` 内に `KrunkerUltraClient.exe` が生成されます。

## ⚠️ 注意事項

*   本クライアントはWindows 10 / 11 専用です。
*   TCPレジストリ最適化機能を使用する場合は、クライアントを「管理者として実行」する必要があります。
